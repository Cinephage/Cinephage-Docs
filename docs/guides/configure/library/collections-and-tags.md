# Collections

Cinephage groups movies by their TMDB collection (e.g., a franchise like the Marvel Cinematic Universe) and can automatically add new entries as they're announced.

## Collections

### Automatic grouping

- Movies that belong to a TMDB collection (`belongs_to_collection`) are grouped together automatically - no manual setup needed
- Collection membership comes from TMDB, so it stays current with TMDB's own data

### Adding a whole collection

When you add a movie that's part of a TMDB collection with other entries missing from your library, the **Add to Library** modal offers a checkbox to add the entire collection at once:

1. Search for and select a movie that belongs to a collection
2. In the Add to Library modal, enable the option to add the rest of the collection
3. Configure root folder, quality profile, and other options as usual
4. Click **Add** - all missing movies in the collection are added along with the one you searched for

### Tracking a collection for future releases

Cinephage can track a TMDB collection so that movies added to it later (e.g., a new sequel) are automatically added to your library, using the root folder, quality profile, monitoring, and search settings you configure when you start tracking it.

:::note[No dedicated collections management page]
There isn't a separate "Library > Collections" page for manually creating custom collections - collections are always tied to a TMDB collection ID.
:::

## Filtering your library

Cinephage doesn't have a separate tagging system or a saved "custom filter" builder. Instead, filtering happens directly on the **Library > Movies** and **Library > TV Shows** pages using their built-in filter and sort controls (monitored status, quality profile, year, genre, rating, and more) - see [Library Views](library-views) for the full list of available filters.
